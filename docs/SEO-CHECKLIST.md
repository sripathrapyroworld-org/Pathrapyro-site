# SEO post-deploy checklist

Complete these steps after deploying the site to production (`https://sripathrapyrocrakers.com`).

## 1. Environment

Ensure Netlify has:

```
NEXT_PUBLIC_SITE_URL=https://sripathrapyrocrakers.com
```

Redeploy after setting this so sitemap URLs and canonical tags use the correct domain.

## 2. Google Search Console

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add property: `sripathrapyrocrakers.com`
3. Verify via DNS (Namecheap) or HTML tag
4. Submit sitemap: `https://sripathrapyrocrakers.com/sitemap.xml`
5. Request indexing for homepage and `/shop`
6. Check **Pages** and **Sitemaps** weekly for errors

## 3. Google Business Profile

1. Create or claim listing: **Sri Pathra Pyro World**
2. Address: 3/178C, Kalayarkurichi, Purnachandrapuram, Virudhunagar, TN 626130
3. Category: Fireworks store / Wholesaler
4. Add all phone numbers, website, hours, photos
5. Post Diwali-season updates and collect customer reviews

## 4. Bing Webmaster Tools

1. Add site at [Bing Webmaster](https://www.bing.com/webmasters)
2. Submit the same sitemap URL

## 5. Directory listings (backlinks)

List the business on:

- Justdial
- Sulekha
- IndiaMART (wholesale angle)
- Local Tamil Nadu business directories

Use consistent NAP (name, address, phone) matching the website contact page.

## 6. Monitor (monthly)

| Metric | Where |
|--------|--------|
| Indexed pages | Search Console → Pages |
| Keyword impressions | Search Console → Performance → filter "Sivakasi" |
| Average position | Search Console → Performance |
| Core Web Vitals | Search Console → Experience |

Target keywords: Sivakasi crackers, Sivakasi crackers online, buy Sivakasi crackers, Sivakasi fireworks, Sivakasi crackers wholesale, crackers wholesale Sivakasi, Sivakasi crackers shop, best crackers in Sivakasi, original Sivakasi crackers.

## 7. If rankings plateau (after 2–3 months)

Consider adding dedicated landing pages and an FAQ section for competitive head terms.
